# References

- `references.bib`: the authoritative citation database used by BibTeX.
- `source_register.md`: source links, citation keys, uses in the thesis, and verification notes.
- `ZapataJuan_2026_InternshipTechReport.pdf`: local copy of the prior project report; original preserved.

Keep any additional downloaded source PDFs here, preferably named after their citation key. Web sources currently remain linked in the register; they have not been downloaded. The example theses remain in `../template_examples/` because they guide structure and layout.

For each new source: verify the original, add one BibTeX entry with a unique key, record its purpose in the register, and cite it in the chapter using `\citep{key}`. Compile the root document to update citation numbers and the bibliography. Only cited entries appear in the bibliography. Never edit `main.bbl`, `main.aux`, or other generated files.

The abbreviations list is maintained separately in `../frontmatter/abbreviations.tex`; it is not generated by BibTeX.

## Internship report use

Keep the author's internship report as background for understanding the work only. Do not cite it in the thesis or include it in the bibliography. Write the thesis methods and contributions directly, distinguishing inherited designs and collaborators' work from the author's contributions. Use external sources for technical claims; do not attach a replacement citation unless it supports the specific claim.
